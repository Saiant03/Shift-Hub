# Brand design references (awesome-design-md)

74 brands, each under `design-md/<brand>/`:

- **`DESIGN.md`** — structured, machine-readable tokens: `colors`, `typography`, spacing, radii, shadows, motion, plus a prose description of the design philosophy.
- **`README.md`** — human summary of the brand's design language.

## How to use

1. Pick the brand closest to the target aesthetic (list below).
2. Read `design-md/<brand>/DESIGN.md` and lift the exact tokens — never approximate a brand's palette or type when the real values are here.
3. Map those tokens onto the project's own system (CSS variables, Tailwind theme, design tokens). Adapt, don't copy blindly — respect the target codebase's conventions.

Great to pair with `apple-design`, `impeccable`, or `ui-ux-pro-max` when polishing a UI.
